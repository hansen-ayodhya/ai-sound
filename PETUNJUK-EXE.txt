AI SOUND ENGINEER - VERSI EXE
================================
Semua fungsi hanya MEMBACA mixer. Tidak ada yang mengubah setting.

PEMASANGAN (sekali saja, di komputer EasyWorship)
1. Buat folder, misalnya  C:\AI-Sound-Engineer
2. Salin file AI-Sound-Engineer.exe ke folder itu.
   (Jangan jalankan langsung dari folder Downloads atau dari dalam file zip.)
3. Klik dua kali AI-Sound-Engineer.exe
   - Bila muncul layar biru "Windows protected your PC":
     klik "More info" lalu "Run anyway". Ini karena exe belum ditandatangani resmi.
   - Bila Windows bertanya soal firewall: centang "Private networks" saja, lalu Allow.
4. Jendela hitam menampilkan alamat dan PIN. Browser terbuka ke halaman Beranda.

MEMBUKA DARI HP / TABLET
- Sambungkan ke Wi-Fi gereja yang sama (yang berpassword).
- Buka browser, ketik alamat yang tampil di jendela hitam (contoh http://192.168.1.23:8765).
- Masukkan PIN 6 angka.

PENTING
- JANGAN tutup jendela hitam selama aplikasi dipakai. Menutupnya = mematikan aplikasi.
- Folder "data" di samping exe berisi hasil audit, IP mixer, dan PIN. Jangan dihapus.
  (Untuk membuat PIN baru: hapus data\pin.txt lalu jalankan exe lagi.)
- Bila hanya ingin dibuka dari komputer ini saja (tanpa HP/tablet):
  buat shortcut exe, lalu di Properties > Target tambahkan  --lokal  di akhir.

UPDATE KE VERSI BARU DARI DALAM APLIKASI (di luar jam ibadah)
1. Beranda > 4. Perawatan > "Cek versi baru". Bila ada, tekan "Perbarui sekarang".
2. Aplikasi mengunduh, menutup sekitar 1 menit, lalu membuka lagi sendiri. Folder data tetap aman.
3. Exe lama disimpan sebagai AI-Sound-Engineer.lama.exe. Bila versi baru bermasalah, tutup aplikasi lalu jalankan file itu.
- Repo proyek private: pertama kali, isi token GitHub baca-saja di bagian yang sama (petunjuknya ada di sana).
- Cara ini baru bisa dipakai mulai dari exe yang sudah memuat tombol tersebut; exe yang lebih lama diganti manual sekali (cara di bawah).

MULAI OTOMATIS SAAT KOMPUTER DINYALAKAN
- Beranda > 4. Perawatan > centang "Jalankan aplikasi otomatis saat komputer dinyalakan".
- Berlaku untuk akun Windows yang sedang dipakai. Bila exe dipindah ke folder lain, matikan lalu nyalakan lagi pilihan ini.

UPDATE MANUAL (cadangan, di luar jam ibadah)
1. Tutup jendela hitam aplikasi.
2. Unduh exe terbaru dari GitHub: repo ai-sound > tab Actions > "AI Sound Engineer EXE"
   > build teratas yang centang hijau > bagian Artifacts > AI-Sound-Engineer-exe (file zip).
3. Buka zip, timpa AI-Sound-Engineer.exe yang lama. Folder data tetap aman.
4. Klik dua kali exe yang baru. Cek "Versi program" di bagian bawah Beranda.

PENGECEKAN SIARAN YOUTUBE (opsional)
1. Simpan Pasang-Alat-Siaran.bat di folder YANG SAMA dengan AI-Sound-Engineer.exe (ada di paket unduhan; kalau Anda hanya mengganti exe, ambil file ini dari paket yang sama).
2. Klik dua kali file itu (butuh internet; mengunduh yt-dlp dan ffmpeg ke folder "tools" di samping exe). Tunggu sampai muncul tulisan SELESAI.
3. Buka AI Sound Engineer (tidak perlu menyalakan ulang komputer). Tampilan Mixer > menu titik tiga > "Siaran YouTube (bus USB)" > tempel link siaran, pilih jeda, klik Simpan atau Cek sekarang.
Cara manual bila unduhan gagal: unduh yt-dlp.exe dan ffmpeg.exe sendiri, lalu salin ke folder "tools" di samping exe.
Cuplikan 15 detik diperiksa di laptop (clipping, kekerasan, senyap). Gemini hanya dipakai bila Anda menekan tombolnya.
Bila suatu hari gagal membuka siaran, perbarui alatnya dengan menjalankan Pasang-Alat-Siaran.bat lagi.
